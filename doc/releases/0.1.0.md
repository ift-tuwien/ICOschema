# Package

- Initial release on PyPI

## 0.1.0b3

### Added

- `PreprocessedRecording` and `DatasetBundle.preprocessed`: the raw channels on the gap-free sample grid with
  timestamps rebased to 1 / sampling frequency, validated against the recording (`with_preprocessed`,
  `without_preprocessed`). Stored as file format `1.1`.
- `Recording.rows_per_packet()`, `sample_index()`, `filled_mask()`, `channel_count`.
- ADC settings `adc_prescaler`, `adc_acquisition_time`, `adc_oversample_rate` on `HardwareMetadata`, and
  `Recording.total_sampling_frequency()` / `channel_sampling_frequency()` (from the recorded settings, else the
  default settings: 9523.81 Hz total).
- `pre_metadata` / `post_metadata` on `RecordingMetadata`.

### Changed

- Files are written gzip-compressed (with shuffle).
- The writer uses format `1.0` unless the bundle has a preprocessed table (`1.1`).
- `DatasetBundle.with_recording` raises while the bundle has a preprocessed table.

### Fixed

- Rewriting a file no longer drops the primary table's `pre_metadata` / `post_metadata` attributes. Other unknown
  attributes are logged as dropped instead of disappearing silently.

## 0.1.0b4

### Added

- `ComputationStep` and `DatasetBundle.steps`: the record of each computation step (producer, parameters, inputs,
  status, summary, the `output_keys` it wrote, timing, environment), ordered by `step_index`. Stored as file format
  `1.2` under `/steps/`.
- `DatasetBundle.with_step`, `without_steps`, `computations_of`, `unmanaged_keys`.

### Changed

- The writer uses format `1.2` when the bundle has steps (else `1.1` with a preprocessed table, else `1.0`).
- `DatasetBundle.with_recording` also raises while the bundle has steps.
- Every `DatasetBundle` copy helper keeps `steps`.
